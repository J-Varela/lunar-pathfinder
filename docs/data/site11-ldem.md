## Interpretation limits

The 5-meter surface is substantially interpolated between LOLA laser
measurements. Pixel resolution must not be interpreted as equivalent
to independent 5-meter ground sampling.

NASA provides accompanying count, elevation-uncertainty, slope, and
slope-uncertainty products. These should be incorporated before making
mission-safety claims.
