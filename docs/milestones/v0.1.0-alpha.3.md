# v0.1.0-alpha.3 — Initial rover route optimization

## Objective

Calculate a safe minimum-cost route across classified synthetic lunar
terrain.

## What was built

- Eight-direction A* route planner
- Terrain-dependent movement costs
- Blocked-cell exclusion
- Diagonal corner-cutting prevention
- Start and destination validation
- No-route detection
- Route distance and weighted-cost calculation
- Per-class route exposure statistics
- Reproducible mission JSON
- Glowing route visualization

## Verification

The complete suite contains 46 passing tests.

Routing tests verify:

- Straight and diagonal movement
- Physical movement distance
- Navigation through a barrier opening
- Selection of a safer route over a hazardous shortcut
- Rejection of blocked endpoints
- Rejection of out-of-bounds endpoints
- Failure when no route exists
- Zero-distance stationary routes
- Valid ordering of terrain costs

## Mission result

The planner routed between opposite regions of the 10.24 km² synthetic
site.

| Measurement | Result |
|---|---:|
| Route cells | 177 |
| Route distance | 4,414.70 m |
| Direct distance | 3,790.09 m |
| Additional distance | 624.61 m |
| Detour factor | 1.1648 |
| Weighted cost | 4,656.12 |
| Preferred cells | 167 |
| Caution cells | 10 |
| Hazardous cells | 0 |
| Blocked cells | 0 |

The selected route remained entirely outside hazardous and blocked
terrain. It accepted a 16.48% distance increase to reduce operational
risk.

The requested endpoints were shifted to their nearest preferred cells.
The landing location moved one cell east, and the science target moved
one cell north.

## Interpretation boundary

This result validates route-planning behavior on deterministic synthetic
terrain. It does not yet represent a real lunar mission or a
vehicle-qualified mobility assessment.
